These fixtures were generated by Apache Iceberg Java 1.12.0 using
`GenerateFixture.java`, with OpenJDK 22.0.2. They contain encrypted Parquet data
`x = [0, 1, 2, 3]`, encrypted manifests and manifest lists, and two alternatives
for deleting positions 1 and 3: encrypted Parquet position deletes and an
encrypted Puffin deletion vector. Both scans must return `[0, 2]`.

The test KMS returns its input unchanged. All keys are disposable test keys.
Paths are relative so the test can run from this directory on any platform.

To regenerate in an empty directory, download these Maven Central artifacts:

- `org.apache.iceberg:iceberg-spark-runtime-4.0_2.13:1.12.0`
- `org.apache.hadoop:hadoop-client-api:3.4.2`
- `org.apache.hadoop:hadoop-client-runtime:3.4.2`
- `org.slf4j:slf4j-api:2.0.18`

Compile `GenerateFixture.java` with the Iceberg jar on the classpath, then run
`org.apache.iceberg.GenerateFixture` with the compiled classes and all four jars
on the classpath. Copy the generated data and metadata files into this directory.
