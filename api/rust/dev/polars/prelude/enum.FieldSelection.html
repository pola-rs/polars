Enum FieldSelection 

pub enum FieldSelection {
    All,
    Fields(Box<IndexMap<PlSmallStr, FieldSelection, RandomState>>),
    Element(Box<FieldSelection>),
}
Available on crate feature lazy only.
Expand description

Which parts of one column’s value are needed.

Built by projection pushdown, which reads struct fields by name; non-struct values are always All. See agent-docs/nested-projection-pushdown/01-field-pruning.md.

Variants§

§

All

The whole value (every field, recursively). The default; all non-nested columns.

§

Fields(Box<IndexMap<PlSmallStr, FieldSelection, RandomState>>)

Only these struct fields, each with its own selection. Empty: only the row count and the outer validity are needed (s.is_null(), len).

§

Element(Box<FieldSelection>)

The element of a List or Array, with its own selection, plus the offsets and validity of the list. Never Element(All), which is All.

Only the row count and the outer validity.

Only the field name, with selection.

The element of a list or array with selection; All if selection is.

pub fn is_all(&self) -> bool

pub fn fields( &self, ) -> Option<&IndexMap<PlSmallStr, FieldSelection, RandomState>>

pub fn child(&self, name: &str) -> Option<&FieldSelection>

The selection of field name: All under All, None if the field is not needed. All for an element selection, which has no fields.

pub fn element_selection(&self) -> &FieldSelection

The selection of the element of a list: All unless an element selection.

pub fn union(&mut self, other: FieldSelection)

Merges the needs of another consumer of the same value into self. All absorbs everything, field maps merge key by key and validity-only is absorbed by any selection.

pub fn insert_child(&mut self, name: PlSmallStr, selection: FieldSelection)

Unions field name with selection into self. Does nothing under All; makes an element selection All, as it has no fields.

pub fn normalize(self, dtype: &DataType) -> FieldSelection

Makes the selection canonical for dtype: non-struct values and structs with every field selected whole become All, and fields that dtype does not have are dropped.

pub fn prune_dtype(&self, dtype: &DataType) -> DataType

The dtype with only the selected fields, in the order of dtype.

pub fn prune_arrow_field(&self, field: &Field) -> Field

Self::prune_dtype for an arrow field: field with only the selected struct fields.

pub fn prune_arrow_dtype(&self, dtype: &ArrowDataType) -> ArrowDataType

Self::prune_dtype for an arrow dtype. Only plain structs and lists are pruned: anything else is kept whole.

pub fn intersect(&self, other: &FieldSelection) -> FieldSelection

What both self and other, two selections of one value, select. self if they are not from one dtype.

pub fn of_target_dtype(dtype: &DataType, target: &DataType) -> FieldSelection

The fields of dtype that target has, matched by name, recursively: what a cast of dtype to target that ignores extra struct fields keeps. A field target has and dtype lacks is left out; a struct none of whose fields target has is needed for its validity only.

pub fn of_narrowed_dtype( dtype: &DataType, narrowed: &DataType, ) -> FieldSelection

The fields of dtype that narrowed, dtype with some struct fields left out, has. Like Self::of_target_dtype, but a struct narrowed has a field of that dtype lacks is not a narrowing of it, and is read whole.
