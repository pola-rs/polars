Struct SharedDictionary 

Source 
pub struct SharedDictionary { /* private fields */ }
Expand description

The values of a dictionary that DictionaryColumns index into, such as the dictionary page of a parquet column chunk.

The values need not be unique: equal codes mean equal values, but different codes may also.
