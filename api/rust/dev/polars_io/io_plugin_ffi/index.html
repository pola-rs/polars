Module io_plugin_ffi 

Source
Available on crate feature io_plugin_ffi only.
Expand description

Host side of the generic I/O plugin contracts of polars_io_ext_ffi: polars.io_plugin.file_reader.v1 (see crate::external_reader::ffi) and polars.io_plugin.lazyframe_resolver.v1 (the Ffi DSL resolver of polars-plan).

Plugins are found by Python package name through polars_io_ext_ffi::registry, whose locator the Python bindings install.
