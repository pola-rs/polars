Module kms 

Source
Available on crate features parquet_kms and parquet only.
Expand description

Parquet modular encryption with keys managed by a KMS, using a KMS client implemented in Python.

The KMS configuration can be serialized, so that queries can be run elsewhere, such as on Polars Cloud. The Python KMS client factory is pickled, and the KMS connection configuration is serialized as is, including the key access token.
